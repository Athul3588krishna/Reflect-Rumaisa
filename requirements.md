# Reflect: Personal Multimedia Diary and Planner

## Problem Statement
Existing diary applications mainly support text-based entries and offer limited multimedia features. Users cannot effectively record daily experiences using audio and video, and many applications lack proper organization, calendar navigation, task management, and efficient search features.

## Objective
To develop a secure full-stack application that allows users to create and manage personal diary entries using text, audio, and video while providing daily planning features.

## Proposed Solution
The application provides secure user registration/login, multimedia diary creation, calendar organization, keyword/date search, a To-Do List, and separate Admin and User modules.

## Admin Module
- Admin Login
- Manage Users
- View Dashboard
- View Diary Activities
- Send Notifications

## User Module
- Register/Login
- Manage Profile
- Create, Edit, View & Delete Entries
- Upload Text, Audio & Video
- Calendar View
- Search & Filter
- To-Do List
- Receive Notifications

## Technology Stack
- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Supabase
- **Database**: PostgreSQL

## Benefits
- Supports text, audio, and video diary entries.
- Easy task management with To-Do List.
- Secure storage.
- Quick search and calendar management.
- Accessible through web and mobile browsers.
